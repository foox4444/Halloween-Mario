# Halloween-Mario
This is a Mario-themed platformer. I made this project to follow the theme of week 2 of 8-bit; I used it to learn how to make platformers, learn more about game development, and learn how to make games in Pygame. I used one block, but I also have more blocks in my images folder that I didn't use. It has coins and a scoring system.
How to play:
 You play using the arrow keys. Use the left arrow to go left and the right arrow to go right. The up arrow lets you jump. You can also respawn and play the game again after you win by pressing the "R" key.
How to get the game:
You can play the game by downloading the exe file. After that, open the file to start playing.
