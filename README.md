# Halloween-Mario
This is a Mario-themed platformer. I made this project to follow the theme of week 2 of 8-bit; I used it to learn how to make platformers, learn more about game development, and learn how to make games in Pygame. I used one block, but I also have more blocks in my images folder that I didn't get to use. (There are 6 blocks in the images folder.) It has coins and a scoring system. You play using the arrow keys. You can also restart the game by pressing the "r" key. You can play the game by using the exe file.
